Why Memory Layout Is Useful

	For the kernel: It decides how to protect and manage each memory region (e.g., prevent writing to code segment).

	For the compiler/linker: It decides where to place variables and functions in the ELF file.

	For developers: Understanding it helps debug crashes, memory leaks, and stack overflows.
		Helps in understanding segmentation faults, stack overflows, memory leaks, and dangling pointers.
