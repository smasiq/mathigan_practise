Important kernel parameters

System V IPC shared memory has 3 key limits:

Parameter	What it means	Default on modern Linux (x86_64)
SHMMAX	Maximum size of one shared memory segment	33554432 (32 MB)
SHMMNI	Maximum number of shared memory segments in the system	4096
SHMALL	Total shared memory pages in system	2097152 (on 4 KB pages ≈ 8 GB)

You can check them:

cat /proc/sys/kernel/shmmax
cat /proc/sys/kernel/shmall
cat /proc/sys/kernel/shmmni
